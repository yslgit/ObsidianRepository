# Java IO 流

## 📖 本章导读

### 学习目标
通过本章学习,你将掌握:
- ✅ 字节流和字符流的区别和使用场景
- ✅ InputStream/OutputStream/Reader/Writer四大抽象类
- ✅ 缓冲流(BufferedXXX)的性能优化原理
- ✅ 文件读写和NIO.2(Path/Files)
- ✅ 对象序列化(Serializable)
- ✅ try-with-resources自动关闭资源

### 核心概念
Java IO分为**字节流**(处理二进制数据)和**字符流**(处理文本,自动编码转换)。**缓冲流**减少系统调用次数提升性能,**NIO.2**(JDK 7+)提供Path/Files API简化文件操作。**对象序列化**将对象转为字节流持久化。

### 知识地图
```
IO流体系
├── 字节流(8bit)
│   ├── InputStream: FileInputStream, BufferedInputStream
│   ├── OutputStream: FileOutputStream, BufferedOutputStream
│   └── 特殊流: DataInputStream, ObjectInputStream, ByteArrayInputStream
├── 字符流(16bit)
│   ├── Reader: FileReader, BufferedReader, InputStreamReader
│   ├── Writer: FileWriter, BufferedWriter, OutputStreamWriter
│   └── 格式化: PrintWriter
├── NIO.2(JDK 7+)
│   ├── Path: 路径表示
│   ├── Files: 文件操作(readAllLines, copy, move)
│   └── DirectoryStream: 目录遍历
├── 序列化
│   ├── Serializable接口: 标记接口
│   ├── transient: 跳过字段
│   └── serialVersionUID: 版本控制
└── 最佳实践
    ├── 始终使用try-with-resources
    ├── 大文件用缓冲流
    ├── 明确指定编码(UTF-8)
    └── 小文件用Files.readAllBytes/write
```

### 常见误区
❌ **误区1**: FileReader可以指定编码
✅ **真相**: FileReader使用平台默认编码,应该用InputStreamReader+FileInputStream

❌ **误区2**: 单字节读取性能可以接受
✅ **真相**: 单字节读取每次触发系统调用,应该用缓冲流或数组读取

❌ **误区3**: 序列化所有字段
✅ **真相**: 敏感字段(transient密码等)和可计算字段不应序列化

### 实战建议
1. **文本文件**: 用BufferedReader/BufferedWriter+UTF-8编码
2. **二进制文件**: 用BufferedInputStream/BufferedOutputStream
3. **小文件**: JDK 7+用Files.readAllBytes/write直接读写
4. **大文件**: 用缓冲流+分块读写,避免OOM
5. **资源管理**: 始终使用try-with-resources自动关闭
6. **编码统一**: 始终明确指定StandardCharsets.UTF_8
7. **NIO优先**: 新项目优先使用java.nio.file.Path/Files

## 1. IO 体系概览

### 1.1 流的分类

```
按流向：
  ├── 输入流（Input）：读取数据
  └── 输出流（Output）：写入数据

按数据单位：
  ├── 字节流（8 bit）：处理二进制数据
  └── 字符流（16 bit）：处理文本数据（自动编码/解码）

按功能：
  ├── 节点流：直接连接数据源（文件、内存、管道）
  └── 处理流：包装节点流，提供额外功能（缓冲、转换、对象序列化）
```

### 1.2 核心抽象类

```
字节输入流：InputStream
  ├── FileInputStream（文件输入）
  ├── ByteArrayInputStream（字节数组输入）
  ├── BufferedInputStream（缓冲输入）
  ├── DataInputStream（基本类型读取）
  ├── ObjectInputStream（对象反序列化）
  └── PipedInputStream（管道输入）

字节输出流：OutputStream
  ├── FileOutputStream（文件输出）
  ├── ByteArrayOutputStream（字节数组输出）
  ├── BufferedOutputStream（缓冲输出）
  ├── DataOutputStream（基本类型写入）
  ├── ObjectOutputStream（对象序列化）
  └── PipedOutputStream（管道输出）

字符输入流：Reader
  ├── FileReader（文件输入）
  ├── CharArrayReader（字符数组输入）
  ├── BufferedReader（缓冲输入）
  ├── InputStreamReader（字节→字符转换）
  │    └── FileReader（实际上是 InputStreamReader 的子类）
  ├── StringReader（字符串输入）
  └── PipedReader（管道输入）

字符输出流：Writer
  ├── FileWriter（文件输出）
  ├── CharArrayWriter（字符数组输出）
  ├── BufferedWriter（缓冲输出）
  ├── OutputStreamWriter（字符→字节转换）
  │    └── FileWriter（同上）
  ├── StringWriter（字符串输出）
  ├── PrintWriter（格式化输出）
  └── PipedWriter（管道输出）
```

## 2. 字节流

### 2.1 FileInputStream / FileOutputStream

```java
// 文件输入流
// JDK 9+：构造器可接受 Path 参数
try (FileInputStream fis = new FileInputStream("input.txt")) {
    int data;
    while ((data = fis.read()) != -1) {   // 单字节读取（慢！）
        System.out.print((char) data);
    }
}

// 使用缓冲区（更快）
try (FileInputStream fis = new FileInputStream("input.txt")) {
    byte[] buffer = new byte[1024];        // 1KB 缓冲区
    int bytesRead;
    while ((bytesRead = fis.read(buffer)) != -1) {
        // buffer 中 [0, bytesRead) 包含有效数据
        process(buffer, bytesRead);
    }
}

// 文件输出流
try (FileOutputStream fos = new FileOutputStream("output.txt")) {
    fos.write("Hello".getBytes());
}

// 追加模式
try (FileOutputStream fos = new FileOutputStream("output.txt", true)) {
    fos.write("Appended".getBytes());
}
```

### 2.2 BufferedInputStream / BufferedOutputStream

```java
// 带缓冲的字节流：减少系统调用次数

// 默认缓冲区大小 8192 字节（8KB）
try (BufferedInputStream bis = new BufferedInputStream(
        new FileInputStream("large.bin"))) {
    byte[] buffer = new byte[4096];
    int bytesRead;
    while ((bytesRead = bis.read(buffer)) != -1) {
        process(buffer, bytesRead);
    }
}

// 指定缓冲区大小
new BufferedInputStream(new FileInputStream("file.bin"), 65536); // 64KB

// 性能对比（读取 100MB 文件）：
// 无缓冲单字节：~5 秒（每次 read() 触发系统调用）
// 无缓冲 4KB 数组：~0.5 秒
// BufferedInputStream 单字节：~0.5 秒（与数组读取几乎一样）
// BufferedInputStream + 数组：~0.3 秒（最佳）
```

### 2.3 DataInputStream / DataOutputStream

```java
// 读写 Java 基本数据类型（与平台无关的二进制格式）

// 写入
try (DataOutputStream dos = new DataOutputStream(
        new FileOutputStream("data.bin"))) {
    dos.writeInt(42);            // 4 字节
    dos.writeDouble(3.14);       // 8 字节
    dos.writeUTF("hello");       // 修改过的 UTF-8 编码
    dos.writeBoolean(true);      // 1 字节
}

// 读取（必须与写入顺序一致）
try (DataInputStream dis = new DataInputStream(
        new FileInputStream("data.bin"))) {
    int i = dis.readInt();
    double d = dis.readDouble();
    String s = dis.readUTF();
    boolean b = dis.readBoolean();
}
```

### 2.4 ByteArrayInputStream / ByteArrayOutputStream

```java
// 内存中的字节流（不需要文件）

// 读取字节数组
byte[] data = {0, 1, 2, 3, 4};
try (ByteArrayInputStream bais = new ByteArrayInputStream(data)) {
    int b;
    while ((b = bais.read()) != -1) {
        System.out.println(b);
    }
}

// 写入到字节数组（常用于收集输出）
try (ByteArrayOutputStream baos = new ByteArrayOutputStream()) {
    baos.write("Hello".getBytes());
    baos.write(" World".getBytes());
    byte[] result = baos.toByteArray();  // "Hello World" 的字节
    System.out.println(baos.toString());  // 或直接 toString
}
```

## 3. 字符流

### 3.1 FileReader / FileWriter

```java
// FileReader：InputStreamReader 的便捷子类
// 使用平台默认编码（❌ 不可移植！）

// ❌ 依赖默认编码
try (FileReader fr = new FileReader("text.txt")) {
    int ch;
    while ((ch = fr.read()) != -1) {
        System.out.print((char) ch);
    }
}

// ✅ 明确指定编码
try (InputStreamReader reader = new InputStreamReader(
        new FileInputStream("text.txt"), StandardCharsets.UTF_8)) {
    int ch;
    while ((ch = reader.read()) != -1) {
        System.out.print((char) ch);
    }
}

// 文件写入
try (FileWriter fw = new FileWriter("output.txt")) {
    fw.write("Hello\n");
    fw.write("World");
}

// 明确指定编码的写入
try (OutputStreamWriter writer = new OutputStreamWriter(
        new FileOutputStream("output.txt"), StandardCharsets.UTF_8)) {
    writer.write("你好");
}
```

### 3.2 BufferedReader / BufferedWriter

```java
// BufferedReader：最常用的文本读取方式
// readLine() 按行读取（自动处理不同平台的换行符）

try (BufferedReader reader = new BufferedReader(
        new FileReader("large.txt"))) {
    String line;
    while ((line = reader.readLine()) != null) {
        System.out.println(line);
    }
}

// 更简洁的写法（Files 工具类）
try (Stream<String> lines = Files.lines(Paths.get("large.txt"))) {
    lines.filter(l -> l.contains("ERROR"))
         .forEach(System.out::println);
}

// BufferedWriter + PrintWriter
try (PrintWriter writer = new PrintWriter(
        new BufferedWriter(new FileWriter("out.txt")))) {
    writer.println("Hello");
    writer.printf("Value: %.2f%n", 3.14);
    writer.println("World");
}
```

### 3.3 转换流的编码问题

```java
// InputStreamReader：字节→字符（解码）
// OutputStreamWriter：字符→字节（编码）

// 在不同编码间转换文件
try (BufferedReader reader = new BufferedReader(
        new InputStreamReader(new FileInputStream("gbk.txt"), "GBK"));
     BufferedWriter writer = new BufferedWriter(
        new OutputStreamWriter(new FileOutputStream("utf8.txt"), "UTF-8"))) {
    String line;
    while ((line = reader.readLine()) != null) {
        writer.write(line);
        writer.newLine();
    }
}
```

## 4. NIO 核心

### 4.1 Files 与 Paths（JDK 7+）

```java
// Files 工具类提供了大量便捷操作

// 读取文件全部内容
List<String> allLines = Files.readAllLines(Paths.get("file.txt"));
String content = Files.readString(Paths.get("file.txt"));  // JDK 11+

// 写入文件
Files.write(Paths.get("out.txt"), "Hello".getBytes());
Files.writeString(Paths.get("out.txt"), "Hello");         // JDK 11+
Files.write(Paths.get("out.txt"), allLines);               // List<String>

// 文件操作
Files.copy(source, target, StandardCopyOption.REPLACE_EXISTING);
Files.move(source, target);
Files.delete(path);
Files.createDirectories(path);   // 创建不存在的父目录

// 文件信息
Files.exists(path);
Files.isDirectory(path);
Files.isRegularFile(path);
Files.size(path);
Files.getLastModifiedTime(path);
Files.probeContentType(path);     // "text/plain"、"image/png"

// 目录遍历
try (Stream<Path> stream = Files.walk(Paths.get("."))) {
    stream.filter(Files::isRegularFile)
          .filter(p -> p.toString().endsWith(".java"))
          .forEach(System.out::println);
}

// 目录下的文件列表
try (Stream<Path> stream = Files.list(Paths.get("."))) {
    stream.forEach(System.out::println);
}
```

### 4.2 FileChannel（JDK 4+）

```java
// FileChannel：面向缓冲区的通道，比流式 IO 更高效
// 支持直接缓冲区（DirectBuffer）、内存映射文件

RandomAccessFile file = new RandomAccessFile("large.bin", "rw");
FileChannel channel = file.getChannel();

// 读取
ByteBuffer buffer = ByteBuffer.allocate(1024);
int bytesRead = channel.read(buffer);  // 读入缓冲区

// 写入
ByteBuffer output = ByteBuffer.wrap("Hello".getBytes());
channel.write(output);

// 零拷贝传输
FileChannel source = new FileInputStream("src.bin").getChannel();
FileChannel dest = new FileOutputStream("dst.bin").getChannel();
source.transferTo(0, source.size(), dest);  // 零拷贝！
// transferTo 利用操作系统内核的 DMA 传输
// 避免了用户态和内核态之间的多次拷贝

// 性能对比（1GB 文件传输）：
// 普通 IO 流：~3-5 秒
// FileChannel 非零拷贝：~2-3 秒
// FileChannel.transferTo：~0.5-1 秒（操作系统零拷贝）
```

### 4.3 内存映射文件（MappedByteBuffer）

```java
// 将文件直接映射到进程虚拟内存，像操作内存一样操作文件
// 适用于大文件（数百 MB ~ GB 级）

RandomAccessFile file = new RandomAccessFile("large.bin", "rw");
FileChannel channel = file.getChannel();

// 映射文件区域到内存
MappedByteBuffer buffer = channel.map(
    FileChannel.MapMode.READ_WRITE,
    0,                // 起始位置
    channel.size()    // 映射长度
);

// 像操作字节数组一样操作文件
int value = buffer.getInt(100);   // 读取偏移 100 处的 int
buffer.putLong(200, 42L);         // 写入偏移 200 处的 long

// 性能：接近内存访问速度（文件数据通过缺页中断按需加载）

// 注意：
// - 由操作系统管理刷盘（可调用 force() 强制写回）
// - 文件大小受虚拟内存地址空间限制
// - 大量映射可能导致虚拟内存耗尽
```

## 5. 对象序列化

### 5.1 Serializable 接口

```java
// 使用 ObjectOutputStream/ObjectInputStream
// 实现 Serializable 接口（标记接口，无方法）

public class User implements Serializable {
    private static final long serialVersionUID = 1L;  // 版本号

    private String name;
    private int age;
    private transient String password;  // transient 字段不序列化
    private static String staticField;  // 静态字段不序列化
}

// 序列化
try (ObjectOutputStream oos = new ObjectOutputStream(
        new FileOutputStream("user.ser"))) {
    oos.writeObject(new User("Alice", 25, "secret"));
}

// 反序列化
try (ObjectInputStream ois = new ObjectInputStream(
        new FileInputStream("user.ser"))) {
    User user = (User) ois.readObject();
    // 构造器不会被调用！
    // 反序列化通过 readObject() 直接创建对象，不调用任何构造器
}
```

### 5.2 serialVersionUID

```java
// 序列化版本号：确保序列化兼容性
private static final long serialVersionUID = 1L;

// 如果未显式声明，JVM 根据类结构自动生成
// 类结构变化（增减字段、方法签名变更）会导致 UID 变化 → InvalidClassException

// 最佳实践：始终显式声明 serialVersionUID
// 兼容性控制：
// - UID 不变：新增字段不影响反序列化（新增字段为默认值）
// - UID 不变：删除字段，被删除字段的值被忽略
// - 更改字段类型或不兼容的结构 → 建议修改 UID 或自定义序列化
```

### 5.3 自定义序列化

```java
public class CustomSerialization implements Serializable {
    private static final long serialVersionUID = 1L;
    private String data;
    private transient String computed;

    // 自定义序列化
    private void writeObject(ObjectOutputStream oos) throws IOException {
        oos.defaultWriteObject();  // 先执行默认序列化
        oos.writeUTF(computeDerivedData());  // 写入额外数据
    }

    // 自定义反序列化
    private void readObject(ObjectInputStream ois) throws IOException, ClassNotFoundException {
        ois.defaultReadObject();
        this.computed = ois.readUTF();  // 读取自定义数据
        // 可以在这里做参数校验（类似构造器的功能）
        if (data == null) {
            throw new InvalidObjectException("data cannot be null");
        }
    }

    // 替换要序列化的对象（单例模式等场景）
    private Object writeReplace() {
        return this;
    }

    // 反序列化时替换对象（枚举使用此机制）
    private Object readResolve() {
        return INSTANCE;  // 返回单例
    }
}
```

### 5.4 Externalizable

```java
// 完全自定义序列化（性能更好，但需手动管理所有字段）
public class User implements Externalizable {
    private String name;
    private int age;

    @Override
    public void writeExternal(ObjectOutput out) throws IOException {
        out.writeUTF(name);
        out.writeInt(age);
    }

    @Override
    public void readExternal(ObjectInput in) throws IOException, ClassNotFoundException {
        name = in.readUTF();
        age = in.readInt();
    }
}
```

## 6. NIO.2：新 IO 特性

### 6.1 WatchService（文件监控）

```java
// 监控文件系统事件（JDK 7+）
Path dir = Paths.get(".");
WatchService watcher = FileSystems.getDefault().newWatchService();
dir.register(watcher,
    StandardWatchEventKinds.ENTRY_CREATE,
    StandardWatchEventKinds.ENTRY_DELETE,
    StandardWatchEventKinds.ENTRY_MODIFY);

while (true) {
    WatchKey key = watcher.take();  // 阻塞等待事件
    for (WatchEvent<?> event : key.pollEvents()) {
        Path fileName = (Path) event.context();
        System.out.println(event.kind() + ": " + fileName);
    }
    if (!key.reset()) break;  // 重置 key
}
```

### Q2: 字节流和字符流的区别？

// 字节流：处理二进制数据（图片、视频、zip）

### Q3: InputStream 的 read() 返回 int 而不是 byte？
```java
// read() 返回 -1 表示读取结束
// byte 的取值范围是 -128~127，无法表示 -1
// 所以使用 int（0~255 表示有效值，-1 表示结束）
```

### Q4: 序列化时 static 和 transient 字段的处理？
```java
// static：不序列化（属于类，不属于对象）
// transient：不序列化（可恢复或敏感数据）
// 
// 反序列化后：
// - transient 字段恢复为默认值（对象默认值）
// - static 字段取当前类的静态值
```

// 方法 1：传统流（JDK 4+）
try (InputStream in = new FileInputStream("src");

}

## 8. 最佳实践

1. **始终使用 try-with-resources**：自动关闭资源，避免泄漏
2. **明确指定字符编码**：不要依赖平台默认编码
3. **使用缓冲流**：`BufferedXxx` 包裹节点流可以大幅提升性能
4. **大文件优先 NIO**：`FileChannel` 或 `Files.lines()` 代替 `BufferedReader`
5. **内存映射大文件**：`MappedByteBuffer` 处理超大文件
6. **序列化版本号显式声明**：`serialVersionUID`
7. **敏感字段标记 transient**：密码等不序列化
8. **传输性能：`transferTo` > `FileChannel` > 缓冲流 > 普通流**
9. **文件操作优先 `Files` 工具类**：比 File 更强大
10. **避免频繁调用单字节 read/write**：使用缓冲区
