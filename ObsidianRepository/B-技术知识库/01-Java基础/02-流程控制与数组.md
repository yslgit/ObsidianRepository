# Java 流程控制与数组

## 📖 本章导读

### 学习目标
通过本章学习,你将掌握:
- ✅ if-else和switch条件分支的使用场景
- ✅ for、while、do-while循环的正确选择
- ✅ break和continue的控制流管理
- ✅ 一维和多维数组的声明、初始化和内存布局
- ✅ Arrays工具类的常用方法
- ✅ 数组的性能优化技巧

### 核心概念
**流程控制**决定了程序的执行路径,**数组**是最基础的数据结构。理解它们对于编写逻辑清晰、高效的代码至关重要。

### 知识地图
```
流程控制
├── 条件分支
│   ├── if-else: 布尔条件判断
│   └── switch: 多路分支(JDK 7+支持String)
├── 循环结构
│   ├── for: 已知循环次数
│   ├── while: 先判断后执行
│   ├── do-while: 先执行后判断
│   └── 增强for-each: 遍历集合/数组
└── 跳转语句
    ├── break: 跳出循环/switch
    └── continue: 跳过本次迭代

数组
├── 一维数组
│   ├── 声明与初始化
│   ├── 内存布局(连续存储)
│   └── 默认值
├── 多维数组
│   ├── 数组的数组(非连续)
│   └── 交错数组(Jagged Array)
├── 数组操作
│   ├── 拷贝: System.arraycopy, Arrays.copyOf
│   ├── 排序: Arrays.sort, parallelSort
│   ├── 搜索: binarySearch
│   └── 转换: toString, asList, stream
└── 高级特性
    ├── 数组协变(Covariance)
    ├── Varargs可变参数
    └── 性能优化(缓存友好性)
```

### 常见误区
❌ **误区1**: switch中忘记break导致fall-through
✅ **正确**: 使用JDK 14+的switch表达式(->语法)避免此问题

❌ **误区2**: `int[] arr = {1,2,3}; arr = {4,5,6};` (重新赋值)
✅ **真相**: 简写形式只能在声明时使用,重新赋值需用`new int[]{4,5,6}`

❌ **误区3**: for-each中可以修改数组元素
✅ **真相**: for-each中的变量是副本,修改不影响原数组

### 实战建议
1. **循环选择**: 已知次数用for,未知次数用while,至少执行一次用do-while
2. **数组拷贝**: 大数组用System.arraycopy(最快),小数组用Arrays.copyOf(简洁)
3. **多维数组**: 优先用一维数组模拟(缓存友好),行优先遍历
4. **Switch优化**: JDK 14+使用switch表达式,更安全更简洁
5. **边界检查**: 始终验证数组索引,避免ArrayIndexOutOfBoundsException

## 1. 流程控制语句

### 1.1 条件分支：if-else

```java
// 基本语法
if (condition) {
    // condition 为 true 时执行
} else if (anotherCondition) {
    // anotherCondition 为 true 时执行
} else {
    // 以上条件均不满足时执行
}
```

**关键细节：**
```java
// 1. condition 必须是 boolean 类型（C/C++ 允许 int，Java 不允许）
if (1) { }  // ❌ 编译错误：int 不能转为 boolean

// 2. 悬垂 else 问题（else 与最近的 if 匹配）
if (false)
    if (true)
        System.out.println("A");
    else  // 这个 else 与第二个 if 匹配！
        System.out.println("B");  // 不会执行

// 3. 推荐始终使用大括号
if (x > 0) doSomething();  // ❌ 危险写法，后续加语句容易出错
```

### 1.2 多路分支：switch

**传统 switch（JDK 7+ 支持 String）：**
```java
// 支持的类型：byte, short, char, int, 枚举（JDK 5+）, String（JDK 7+）
// 不支持 long, float, double, boolean

int day = 3;
switch (day) {
    case 1:
        System.out.println("周一");
        break;  // 必须 break，否则 fall-through
    case 2:
        System.out.println("周二");
        break;
    case 3:
        System.out.println("周三");
        break;
    default:
        System.out.println("未知");
}
```

**fall-through 机制：**
```java
// fall-through 是有意设计的特性，用于合并多个 case
int month = 2;
int daysInMonth;
switch (month) {
    case 1: case 3: case 5: case 7: case 8: case 10: case 12:
        daysInMonth = 31;
        break;
    case 4: case 6: case 9: case 11:
        daysInMonth = 30;
        break;
    case 2:
        daysInMonth = 28;  // 不考虑闰年
        break;
    default:
        throw new IllegalArgumentException("Invalid month: " + month);
}

// fall-through 陷阱：忘记 break
int x = 0;
switch (x) {
    case 0:
        System.out.println("zero");
        // 没有 break！
    case 1:
        System.out.println("one");  // 也会输出！
        break;
    default:
        System.out.println("other");
}
// 输出：zero\none
```

**switch 表达式（JDK 12+ 预览，JDK 14+ 正式）：**
```java
// -> 语法：无需 break，无 fall-through
String result = switch (day) {
    case 1 -> "周一";
    case 2 -> "周二";
    case 3 -> "周三";
    case 4, 5 -> "周四周五";  // 多值合并
    default -> "周末";
};

// yield 返回值（代码块中）
String result = switch (day) {
    case 1 -> {
        System.out.println("周一");
        yield "Monday";
    }
    case 2 -> "Tuesday";
    default -> "Unknown";
};

// 穷举性检查：switch 表达式必须覆盖所有可能值
// 对于枚举，必须覆盖所有枚举常量，不然编译错误
enum Color { RED, GREEN, BLUE }
String desc = switch (color) {
    case RED -> "红色";
    case GREEN -> "绿色";
    case BLUE -> "蓝色";
    // 没有 default 也 OK，因为枚举已穷举
};

// switch 表达式的类型必须是统一或兼容的
int len = switch (str) {
    case null -> 0;      // JDK 17+ 支持 null case
    case "hello" -> 5;
    default -> str.length();
};
```

**switch 的编译原理：**
```java
// 1. int 类型 switch：编译为 tableswitch（连续值）或 lookupswitch（稀疏值）
// tableswitch：O(1) 跳转表
// lookupswitch：O(log n) 二分查找

// 2. String 类型 switch：先计算 hashCode，再 switch int，最后 equals 确认
// 实际上是编译器的语法糖

// 3. 枚举 switch：先获取枚举的 ordinal（int），再 switch int
```

### 1.3 循环语句

**for 循环：**
```java
// 标准 for
for (int i = 0; i < 10; i++) {
    System.out.println(i);
}

// 多变量
for (int i = 0, j = 10; i < j; i++, j--) {
    System.out.println(i + " " + j);
}

// 无限循环
for (;;) { }  // 相当于 while(true)

// 空循环体
int sum = 0;
for (int i = 1; i <= 100; sum += i++);  // 分号表示空语句
```

**增强 for-each（JDK 5+）：**
```java
int[] arr = {1, 2, 3, 4, 5};
for (int num : arr) {
    System.out.println(num);
}

// 编译后的等价代码（数组）：
for (int i = 0; i < arr.length; i++) {
    int num = arr[i];
    System.out.println(num);
}

// 编译后的等价代码（Iterable）：
// for-each 在 Iterable 上等价于使用 Iterator：
List<String> list = Arrays.asList("A", "B", "C");
for (String s : list) { }

// 等价于：
for (Iterator<String> it = list.iterator(); it.hasNext(); ) {
    String s = it.next();
}
```

**while 与 do-while：**
```java
// while：先判断再执行（可能一次都不执行）
while (condition) {
    // 循环体
}

// do-while：先执行再判断（至少执行一次）
do {
    // 循环体
} while (condition);  // ❌ 注意分号！
```

**break 与 continue：**
```java
// break：跳出当前循环
for (int i = 0; i < 10; i++) {
    if (i == 5) break;  // 跳出整个 for 循环
    System.out.println(i);  // 输出 0,1,2,3,4
}

// continue：跳过当前迭代，进入下一次
for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) continue;  // 跳过偶数
    System.out.println(i);  // 输出 1,3,5,7,9
}

// 带标签的 break 和 continue（跳出多层循环）
outer:
for (int i = 0; i < 5; i++) {
    for (int j = 0; j < 5; j++) {
        if (i == 2 && j == 2) {
            break outer;  // 直接跳出两层循环
        }
        System.out.println(i + "," + j);
    }
}

// 标签可以用于任何语句块
block:
{
    if (condition) break block;  // 跳出语句块
    doSomething();
}
```

### 1.4 控制流中的变量作用域

```java
// for 循环变量的作用域仅限于循环内部
for (int i = 0; i < 10; i++) { }
// System.out.println(i);  // ❌ 编译错误

// 循环内声明变量
for (int i = 0; i < 3; i++) {
    int x = i * 2;  // 每次迭代都会重新声明
    System.out.println(x);
}

// if 语句中声明的变量
if (condition) {
    int x = 10;  // 作用域仅限于 if 块
}
```

## 2. 数组

### 2.1 数组的声明与初始化

```java
// 声明
int[] arr1;         // ✅ 推荐
int arr2[];         // ✅ 也可以（C 风格，不推荐）
int[] arr3;         // int[] 是类型

// 初始化
int[] nums = new int[5];           // 默认值：[0, 0, 0, 0, 0]
int[] initialized = {1, 2, 3, 4, 5};  // 静态初始化（简写形式）
int[] explicit = new int[]{1, 2, 3};   // 静态初始化（完整形式）

// 简写形式的限制：只能在声明时使用
int[] arr;
arr = {1, 2, 3};        // ❌ 编译错误
arr = new int[]{1, 2, 3};  // ✅ 正确

// 声明与初始化分离（完整形式）
int[] arr;
arr = new int[10];
```

### 2.2 数组的内存布局

```java
// 一维数组的内存布局
int[] arr = new int[3];
arr[0] = 10;
arr[1] = 20;
arr[2] = 30;
```

```
栈内存:   [arr: 0x1000]       ← 引用指向堆内存
          ↓
堆内存:   0x1000: [length: 3]  ← 对象头（Mark Word + Klass Pointer + 长度）
          0x100C: [10]          ← arr[0]
          0x1010: [20]          ← arr[1]
          0x1014: [30]          ← arr[2]
```

**对象数组的内存布局：**
```java
String[] strs = new String[3];
strs[0] = "hello";
strs[1] = null;
strs[2] = "world";
```

```
堆内存:
  0x1000: [length: 3]          ← String[] 对象
  0x100C: [0x2000]             ← strs[0] → 指向 String 对象
  0x1010: [null]                ← strs[1]
  0x1014: [0x3000]             ← strs[2] → 指向 String 对象
          ↓
  0x2000: [String("hello")]
  0x3000: [String("world")]
```

**数组长度在 Java 中是对象头的一部分：**
```java
// 数组长度存储在对象头中，而非结束标记（如 C 的 '\0'）
int[] arr = new int[10];
System.out.println(arr.length);  // 10

// length 是数组的 final 属性，不是方法
// JVM 通过 arraylength 指令获取，效率极高
```

### 2.4 多维数组

Java 的多维数组本质上是**数组的数组**（即交错数组 Jagged Array）：

```java
// 矩形二维数组
int[][] matrix = new int[3][4];  // 3 行 4 列
matrix[0][0] = 1;

// 交错数组（每行长度可以不同）
int[][] jagged = new int[3][];
jagged[0] = new int[1];
jagged[1] = new int[2];
jagged[2] = new int[3];

// 静态初始化
int[][] grid = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};
```

**多维数组的内存模型：**
```java
int[][] matrix = new int[3][4];
```

```
栈: [matrix: 0x1000]
     ↓
堆:  0x1000: [length: 3]      ← int[][]（外层数组）
     0x100C: [0x2000]          ← matrix[0] → int[4]
     0x1010: [0x3000]          ← matrix[1] → int[4]
     0x1014: [0x4000]          ← matrix[2] → int[4]
               ↓                    ↓                    ↓
     0x2000: [length: 4][0][0][0][0]
     0x3000: [length: 4][0][0][0][0]
     0x4000: [length: 4][0][0][0][0]
```

**Java 没有真正的多维数组（C 风格连续内存布局）：**
```java
// C 的 int[3][4] 是连续的 12 个 int（3*4*4=48 字节连续）
// Java 的 int[3][4] 是 1 个外层数组 + 3 个内层数组（非连续）

// 这导致：
// 1. 每行可以独立赋值
matrix[0] = new int[10];  // ✅ 可以重新分配行
// 2. 访问速度比连续布局稍慢（多一次间接寻址）
// 3. 内存碎片更多

// 需要连续大块内存时，可用一维数组模拟
int rows = 3, cols = 4;
int[] flat = new int[rows * cols];
int value = flat[row * cols + col];  // 手动计算索引
```

### 2.5 数组的拷贝

```java
int[] src = {1, 2, 3, 4, 5};
int[] dest = new int[5];

// 1. System.arraycopy（Native 方法，效率最高）
System.arraycopy(src, 0, dest, 0, src.length);

// 2. Arrays.copyOf（内部调用了 arraycopy）
int[] copy = Arrays.copyOf(src, src.length);       // 完整拷贝
int[] partial = Arrays.copyOf(src, 3);             // 只拷贝前 3 个：[1, 2, 3]
int[] range = Arrays.copyOfRange(src, 1, 4);       // [2, 3, 4]

// 3. clone
int[] cloned = src.clone();  // 浅拷贝

// 4. 手动 for 循环（可控但慢）

// 浅拷贝 vs 深拷贝（对象数组）
String[][] original = {{"A", "B"}, {"C", "D"}};
String[][] shallow = original.clone();           // 只拷贝外层引用
String[][] deep = new String[2][];
for (int i = 0; i < original.length; i++) {
    deep[i] = original[i].clone();               // 递归拷贝内层
}
```

**System.arraycopy 的性能优势：**
```java
// System.arraycopy 是 JVM intrinsic 方法
// JIT 会将其编译为高度优化的 memmove 指令（可能使用 SIMD/REP MOVS）
// 比手动 for 循环快 2-5 倍（数据量大时差异更明显）

// 原方法签名：
// public static native void arraycopy(
//     Object src,  int srcPos,
//     Object dest, int destPos,
//     int length
// );
```

### 2.6 Arrays 工具类详解

```java
int[] arr = {5, 3, 1, 4, 2};

// 排序
Arrays.sort(arr);                    // [1, 2, 3, 4, 5]（Dual-Pivot QuickSort）
Arrays.sort(arr, 0, 3);              // 部分排序 [1, 3, 5, 4, 2]
// 对象数组排序使用 TimSort（稳定排序、归并+插入混合）

// 并行排序（JDK 8+）
Arrays.parallelSort(arr);            // 利用 ForkJoinPool，数据量大时更快

// 二分搜索（要求已排序）
int index = Arrays.binarySearch(arr, 3);  // 返回 2
int notFound = Arrays.binarySearch(arr, 6);  // 返回 -6（插入点负数）

// 填充
Arrays.fill(arr, 0);                 // 全部填 0
Arrays.fill(arr, 1, 4, 9);          // [0, 9, 9, 9, 0]（范围填充）

// 比较
int[] arr1 = {1, 2, 3};
int[] arr2 = {1, 2, 3};
System.out.println(arr1 == arr2);                  // false（引用比较）
System.out.println(Arrays.equals(arr1, arr2));      // true（逐元素比较）

// 多维数组比较
int[][] deep1 = {{1, 2}, {3, 4}};
int[][] deep2 = {{1, 2}, {3, 4}};
System.out.println(Arrays.equals(deep1, deep2));    // false（浅层 equals）
System.out.println(Arrays.deepEquals(deep1, deep2)); // true（深层比较）

// 转字符串
System.out.println(Arrays.toString(arr));    // [1, 2, 3, 4, 5]
int[][] matrix = {{1, 2}, {3, 4}};
System.out.println(Arrays.deepToString(matrix));  // [[1, 2], [3, 4]]

// 流操作（JDK 8+）
int sum = Arrays.stream(arr).sum();              // 15
long count = Arrays.stream(arr).filter(x -> x > 2).count();  // 3
```

### 2.7 数组的缺陷与替代方案

```java
// 1. 长度固定，无法动态扩展
int[] arr = new int[3];
// arr[3] = 4;  // ❌ ArrayIndexOutOfBoundsException

// 手动扩容（性能差）
int[] newArr = Arrays.copyOf(arr, arr.length * 2);  // 扩容为 2 倍

// 2. 只能通过索引访问（无 Map 的键值对）
// 3. 不支持泛型数组
// List<Integer>[] arr = new List<Integer>[5];  // ❌ 编译错误
// 4. 打印需要 Arrays.toString（直接打印得到地址）

// 替代方案：
// - 动态数组 → ArrayList
// - 链表 → LinkedList
// - 键值对 → HashMap
// - 线程安全 → CopyOnWriteArrayList / Vector
```

### 2.8 数组协变（Covariance）

```java
// Java 数组是协变的：如果 S 是 T 的子类，则 S[] 是 T[] 的子类
String[] strings = new String[10];
Object[] objects = strings;  // ✅ 编译通过（String[] 是 Object[] 的子类型）

// 运行时检查！
objects[0] = "hello";        // ✅ String 是 Object 的子类
objects[0] = 123;            // ❌ ArrayStoreException！
// 编译通过（int 自动装箱为 Integer，Integer 是 Object），
// 但运行时检查发现 objects 实际是 String[]，拒绝 Integer

// 对比：泛型是"不变"（Invariant）
// List<String> 不是 List<Object> 的子类型
List<String> stringList = new ArrayList<>();
// List<Object> objectList = stringList;  // ❌ 编译错误

// 数组协变的设计缺陷：
// Java 设计者为了兼容性（如 equals(Object[]) 的传参）保留了协变
// 实践中认为这是 Java 早期的一个设计失误
```

### 2.9 数组与 Stream 的互操作

```java
int[] intArr = {1, 2, 3, 4, 5};
String[] strArr = {"a", "b", "c"};

// int[] → IntStream
IntStream stream = Arrays.stream(intArr);              // 整个数组
IntStream range = Arrays.stream(intArr, 1, 4);        // [2, 3, 4]

// T[] → Stream<T>
Stream<String> s = Arrays.stream(strArr);

// Stream → 数组
int[] array = IntStream.range(0, 10).toArray();       // [0..9]
String[] strArray = Stream.of("a", "b").toArray(String[]::new);

// 集合 ↔ 数组
String[] fromList = list.toArray(new String[0]);       // 集合 → 数组
List<String> fromArray = Arrays.asList(strArr);        // 数组 → 集合
// ⚠️ asList 返回的是固定大小的 List（内部仍是数组），不可 add/remove
// 需要可变 List：
List<String> mutableList = new ArrayList<>(Arrays.asList(strArr));
// 或 JDK 8+：
List<String> mutableList = Stream.of(strArr).collect(Collectors.toList());
```

### 2.10 Varargs（可变参数）

```java
// 可变参数本质上是数组的语法糖
public void printAll(String... args) {
    for (String s : args) {
        System.out.println(s);
    }
}

// 调用方式
printAll();              // args = new String[0]
printAll("a");           // args = new String[]{"a"}
printAll("a", "b");      // args = new String[]{"a", "b"}
printAll(new String[]{"a", "b", "c"});  // 直接传数组

// 可变参数规则：
// 1. 只能作为方法最后一个参数
// 2. 只允许一个可变参数
public void method(int x, String... args) { }  // ✅
// public void method(String... args, int x) { }  // ❌

// 方法重载的优先级
printAll();        // 优先匹配无参版本（如果有）
// 当同时存在 printAll() 和 printAll(String...) 时
// 调用无参 printAll() 会匹配无参版本，而非空数组版本

// 泛型与可变参数（@SafeVarargs）
@SafeVarargs
public static <T> List<T> asList(T... elements) {
    // @SafeVarargs 抑制堆污染警告
    // 仅在方法内部不修改可变参数数组元素时使用
    return Arrays.asList(elements);
}
```

### 3.2 性能优化与 JVM 内联

```java
// 1. 数组访问的 JIT 优化
// JVM 对边界检查会进行优化：
// - 循环中数组长度不变时，可在循环开始前提取长度，消除内层检查
// - 如果循环变量范围确定在 [0, length) 内，可完全消除边界检查

// JIT 优化后的数组遍历：
for (int i = 0; i < arr.length; i++) {
    // arr.length 被提升到循环外
    // 边界检查被消除（如果 JIT 能证明 i 不越界）
}

// 2. 循环展开
// JIT 可能将短循环展开以减少分支和指令数

// 3. 数组的缓存友好性
// 顺序访问数组比链表快很多（空间局部性 + 硬件预取）
// 列优先 vs 行优先（Java 多维数组是行优先）
int[][] matrix = new int[10000][10000];

// ✅ 快：行优先遍历（连续内存访问）
for (int i = 0; i < matrix.length; i++) {
    for (int j = 0; j < matrix[i].length; j++) {
        matrix[i][j] = 1;
    }
}

// ❌ 慢：列优先遍历（跳转访问，缓存缺失严重）
for (int j = 0; j < matrix[0].length; j++) {
    for (int i = 0; i < matrix.length; i++) {
        matrix[i][j] = 1;
    }
}
// 性能差距可达 10-100 倍！
```

### Q2: `Arrays.asList()` 返回的 List 有什么限制？
```java
String[] arr = {"A", "B", "C"};
List<String> list = Arrays.asList(arr);

list.set(0, "X");  // ✅ OK，修改反映到原数组
// list.add("D");  // ❌ UnsupportedOperationException
// list.remove(0); // ❌ UnsupportedOperationException

// 原因：返回的是 Arrays 内部的 ArrayList（不是 java.util.ArrayList）
// 内部包装了原数组，大小固定
```

### Q3: 如何将 int[] 转换为 List<Integer>？
```java
int[] intArr = {1, 2, 3};

// ❌ 错误方式
List<int[]> list1 = Arrays.asList(intArr);  // 整个数组作为单个元素！

// ✅ 正确方式（JDK 8+）
List<Integer> list2 = Arrays.stream(intArr)
    .boxed()                          // int → Integer
    .collect(Collectors.toList());

// ✅ 传统方式
List<Integer> list3 = new ArrayList<>();
for (int value : intArr) {
    list3.add(value);
}
```

### Q4: 为什么 Java 不直接支持泛型数组？
```java
// 因为数组是协变的，而泛型是不变的
// 结合两者会导致类型安全问题

// 假如支持：
// List<String>[] arr = new List<String>[5];  // 假设可以
// Object[] objArr = arr;                     // 数组协变
// objArr[0] = new ArrayList<Integer>();      // 堆污染！
// String s = arr[0].get(0);                  // ClassCastException

// 解决方案：使用 ArrayList<ArrayList<T>> 替代 T[][]
// 或使用 @SuppressWarnings("unchecked") 在内部实现中使用
```

### Q5: 如何高效复制大数组？
```java
// 性能对比（百万级元素）：
// System.arraycopy > Arrays.copyOf > clone >> for 循环

// System.arraycopy 最快：native 方法，JVM intrinsic
// Arrays.copyOf 内部调用 arraycopy
// clone 也调用 native 方法但需要类型检查
```

### Q6: for-each 能否修改数组元素？
```java
int[] arr = {1, 2, 3};
for (int x : arr) {
    x = 0;  // 只修改了局部变量 x，不影响数组
}
System.out.println(Arrays.toString(arr));  // [1, 2, 3]

// 正确修改方式：
for (int i = 0; i < arr.length; i++) {
    arr[i] = 0;
}

// 对象数组可以修改对象内容（但不能替换引用）
StringBuilder[] builders = {new StringBuilder("A")};
for (StringBuilder sb : builders) {
    sb.append("B");  // ✅ 修改对象内部状态
    // sb = new StringBuilder("C");  // ❌ 只修改局部变量引用
}
```

## 5. 最佳实践

1. **使用增强 for-each 遍历数组**：除非需要索引
2. **使用 System.arraycopy 复制大数组**：比手动循环快得多
3. **优先 Arrays 工具类**：排序、搜索、填充等用工具类方法
4. **小心数组协变**：存储前确认类型，避免 ArrayStoreException
5. **避免多维数组**：用一维数组手动索引代替（缓存友好）
6. **提前分配足够容量**：避免频繁扩容（Arrays.copyOf 是 O(n) 操作）
7. **并行排序处理大数据**：`Arrays.parallelSort` 在元素数 > 8192 时优势明显
8. **注意 for-each 不能修改数组元素**：需要索引时用普通 for
9. **使用 varargs 时注意空数组**：可变参数可以传空，始终对参数做 null 检查
10. **ArrayIndexOutOfBoundsException 预防**：始终检查索引边界，或在循环中使用增强 for
