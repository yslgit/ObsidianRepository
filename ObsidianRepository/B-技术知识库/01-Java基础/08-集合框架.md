# Java 集合框架

## 📖 本章导读

### 学习目标
通过本章学习,你将掌握:
- ✅ Collection和Map两大体系的结构和区别
- ✅ ArrayList/LinkedList/HashMap/TreeSet等常用实现类
- ✅ 各集合类的底层数据结构和时间复杂度
- ✅ 线程安全集合(ConcurrentHashMap/CopyOnWriteArrayList)
- ✅ 集合的遍历和Stream操作
- ✅ 集合选择最佳实践

### 核心概念
Java集合框架提供**List**(有序可重复)、**Set**(无序不重复)、**Queue**(队列)、**Map**(键值对)四大接口。**ArrayList**基于数组,**HashMap**基于哈希表+红黑树(JDK 8+),理解底层原理对于性能优化至关重要。

### 知识地图
```
集合框架
├── List(有序,可重复)
│   ├── ArrayList: 动态数组,随机访问O(1),扩容1.5倍
│   ├── LinkedList: 双向链表,头尾操作O(1)
│   └── Vector: 遗留类,线程安全(synchronized)
├── Set(无序,不重复)
│   ├── HashSet: HashMap实现,O(1)增删查
│   ├── LinkedHashSet: 维护插入顺序
│   └── TreeSet: 红黑树,O(log n),可排序
├── Queue(队列)
│   ├── PriorityQueue: 堆实现,优先级队列
│   ├── ArrayDeque: 循环数组,双端队列
│   └── BlockingQueue: 阻塞队列(生产者-消费者)
├── Map(键值对)
│   ├── HashMap: 哈希表+链表/红黑树,JDK 8优化
│   ├── LinkedHashMap: 维护插入/访问顺序(LRU缓存)
│   ├── TreeMap: 红黑树,键可排序
│   └── ConcurrentHashMap: 分段锁/CAS,高并发
├── 工具类
│   ├── Collections: sort,shuffle,synchronizedXXX
│   └── Arrays: asList,sort,binarySearch
└── 迭代器
    ├── Iterator: hasNext,next,remove
    ├── ListIterator: 双向遍历
    └── Fail-Fast vs Fail-Safe
```

### 常见误区
❌ **误区1**: `ArrayList`在任何场景都比`LinkedList`快
✅ **真相**: ArrayList随机访问快,LinkedList头尾操作快,中间插入两者都慢

❌ **误区2**: `HashMap`是线程安全的
✅ **真相**: HashMap非线程安全,多线程用ConcurrentHashMap

❌ **误区3**: for-each遍历时可以调用list.remove()
✅ **真相**: for-each使用Iterator,直接调用list.remove()会抛ConcurrentModificationException

### 实战建议
1. **默认选择**: 大多数场景用ArrayList/HashMap
2. **线程安全**: 高并发用ConcurrentHashMap/CopyOnWriteArrayList
3. **初始容量**: 预估数据量,避免频繁扩容`new ArrayList<>(expectedSize)`
4. **不可变集合**: JDK 9+用`List.of()`,`Set.of()`,`Map.of()`
5. **遍历删除**: 用Iterator.remove()或removeIf(),不要for-each中直接remove
6. **HashMap调优**: 负载因子0.75,桶数2的幂次方
7. **LRU缓存**: 用LinkedHashMap(accessOrder=true)

## 1. 集合框架概览

### 1.1 层次结构

```
Collection（接口）
 ├── List（有序、可重复）
 │    ├── ArrayList（数组实现）
 │    ├── LinkedList（双向链表）
 │    ├── Vector（线程安全的动态数组，遗留类）
 │    │    └── Stack（栈，遗留类）
 │    └── CopyOnWriteArrayList（线程安全，JUC）
 ├── Set（无序、不可重复）
 │    ├── HashSet（哈希表）
 │    │    └── LinkedHashSet（维护插入顺序）
 │    ├── TreeSet（红黑树，可排序）
 │    └── CopyOnWriteArraySet（线程安全，JUC）
 └── Queue（队列，FIFO）
      ├── LinkedList（也实现了 Queue）
      ├── PriorityQueue（优先级队列）
      ├── ArrayDeque（双端队列）
      └── BlockingQueue（阻塞队列，JUC）

Map（接口，键值对）
 ├── HashMap（哈希表）
 │    ├── LinkedHashMap（维护插入顺序或访问顺序）
 ├── TreeMap（红黑树，键可排序）
 ├── Hashtable（线程安全，遗留类）
 └── ConcurrentHashMap（线程安全，JUC）
```

### 1.2 核心接口概览

| 接口 | 特点 | 实现类 | 底层结构 |
|:---|:---|:---|:---|
| `List` | 有序、可重复、有索引 | ArrayList / LinkedList | 数组 / 双向链表 |
| `Set` | 无序、不可重复 | HashSet / TreeSet | 哈希表 / 红黑树 |
| `Queue` | FIFO 队列 | LinkedList / PriorityQueue | 链表 / 堆（数组） |
| `Deque` | 双端队列 | ArrayDeque / LinkedList | 循环数组 / 链表 |
| `Map` | 键值对、键不可重复 | HashMap / TreeMap | 哈希表 / 红黑树 |

## 2. List 接口

### 2.1 ArrayList

```java
// 底层：Object[] 数组，可动态扩容
// 特点：随机访问 O(1)，插入/删除 O(n)
// 适用场景：频繁读取、偶尔修改

// 创建
List<String> list = new ArrayList<>();               // 默认容量 10
List<String> list2 = new ArrayList<>(100);           // 指定初始容量
List<String> list3 = new ArrayList<>(otherList);     // 从已有集合创建

// JDK 9+ 的便捷创建
List<String> immutable = List.of("a", "b", "c");     // 不可变！
// List.of 返回的列表不能 add/remove/set
// immutable.add("d");  // ❌ UnsupportedOperationException

// 常用操作
list.add("a");               // 尾部追加
list.add(0, "b");            // 指定位置插入（O(n)）
list.get(0);                 // 随机访问（O(1)）
list.set(0, "c");            // 替换（O(1)）
list.remove(0);              // 按索引删除（O(n)）
list.remove("a");            // 按对象删除（O(n)）
list.indexOf("a");           // 查找位置（O(n)）
list.contains("a");          // 是否包含（O(n)）
list.size();                 // 元素数量
list.isEmpty();              // 是否为空
list.clear();                // 清空
```

**ArrayList 扩容机制（JDK 8+）：**
```java
// 添加元素时的源码分析
private void add(E e, Object[] elementData, int s) {
    if (s == elementData.length)  // 满了
        elementData = grow();     // 扩容
    elementData[s] = e;
}

// 扩容策略
private Object[] grow() {
    return grow(size + 1);
}

private Object[] grow(int minCapacity) {
    int oldCapacity = elementData.length;
    // JDK 8+: 新容量 = 旧容量 + 旧容量 >> 1（1.5 倍）
    int newCapacity = oldCapacity + (oldCapacity >> 1);
    if (newCapacity - minCapacity < 0)
        newCapacity = minCapacity;
    if (newCapacity - MAX_ARRAY_SIZE > 0)
        newCapacity = hugeCapacity(minCapacity);
    return elementData = Arrays.copyOf(elementData, newCapacity);
}
// 扩容代价：每次扩容需要 O(n) 的数组拷贝
// 扩容次数：从 10 到 10000，大约 log_1.5(10000/10) ≈ 14 次
// 优化：如果能预估数据量，预设初始容量
```

**ArrayList 的序列化优化：**
```java

// 序列化时只序列化实际元素（size 个），而非整个数组
// 通过 writeObject 自定义序列化实现
// 反序列化时重新分配 size 大小的数组
```

### 2.2 LinkedList

```java
// 底层：双向链表
// 特点：头尾插入/删除 O(1)，中间操作 O(n)，随机访问 O(n)
// 适用场景：频繁头尾操作、队列/栈

LinkedList<String> list = new LinkedList<>();

// Deque 操作
list.addFirst("a");       // 头插
list.addLast("b");        // 尾插
list.getFirst();          // 头取
list.getLast();           // 尾取
list.removeFirst();       // 头删
list.removeLast();        // 尾删

// 作为栈使用
list.push("a");           // 入栈（= addFirst）
list.pop();               // 出栈（= removeFirst）
list.peek();              // 查看栈顶（= getFirst）

// 作为队列使用
list.offer("a");          // 入队（= addLast）
list.poll();              // 出队（= removeFirst）
list.element();           // 查看队首（= getFirst）
```

**LinkedList 节点结构：**
```java
// 内部类 Node（双向链表节点）
private static class Node<E> {
    E item;          // 当前元素
    Node<E> next;    // 后驱
    Node<E> prev;    // 前驱

    Node(Node<E> prev, E element, Node<E> next) {
        this.item = element;
        this.next = next;
        this.prev = prev;
    }
}
```

### 2.3 ArrayList vs LinkedList

| 操作 | ArrayList | LinkedList |
|:---|:---|:---|
| `get(int)` | O(1) | O(n) |
| `add(E)` | O(1)* | O(1) |
| `add(int, E)` | O(n) | O(n) |
| `remove(int)` | O(n) | O(n) |
| 内存 | 连续内存，有空间浪费 | 每个节点额外 2 个引用 |
| 容量 | 需要时扩容 | 无需预分配 |

> * `add(E)` 平摊 O(1)，但扩容时 O(n)

**选择建议：**
- 读取多 → ArrayList
- 头尾操作多 → LinkedList
- 中间插入/删除多 → 两者都不好，考虑其他数据结构

### 2.4 List 的遍历方式

```java
List<String> list = new ArrayList<>();

// 1. for-each（推荐，简洁）
for (String s : list) { System.out.println(s); }

// 2. 普通 for（需要索引时）
for (int i = 0; i < list.size(); i++) {
    System.out.println(list.get(i));
}

// 3. Iterator（需在遍历中删除时）
Iterator<String> it = list.iterator();
while (it.hasNext()) {
    String s = it.next();
    if (s.startsWith("a")) {
        it.remove();  // ✅ 安全的删除方式
    }
}

// 4. forEach (Lambda，JDK 8+)
list.forEach(System.out::println);

// 5. ListIterator（双向遍历）
ListIterator<String> li = list.listIterator();
while (li.hasNext()) { li.next(); }
while (li.hasPrevious()) { li.previous(); }

// 6. Stream（JDK 8+）
list.stream().filter(s -> s.length() > 2).collect(Collectors.toList());
```

## 3. Set 接口

### 3.1 HashSet

```java
// 底层：HashMap（存储为 HashMap 的 key）
// 特点：无序、O(1) 查找、元素必须实现 hashCode() 和 equals()
// 不保证顺序（甚至可能随时间变化）

Set<String> set = new HashSet<>();     // 初始容量 16，负载因子 0.75
set.add("a");
set.add("b");
set.add("a");           // ✅ 不会重复添加（返回 false）
set.contains("a");      // O(1)
set.remove("a");        // O(1)
set.size();             // 元素数量

// 批量操作
Set<String> a = new HashSet<>(Arrays.asList("a", "b", "c"));
Set<String> b = new HashSet<>(Arrays.asList("b", "c", "d"));

Set<String> union = new HashSet<>(a);    union.addAll(b);       // 并集：[a,b,c,d]
Set<String> inter = new HashSet<>(a);    inter.retainAll(b);    // 交集：[b,c]
Set<String> diff = new HashSet<>(a);     diff.removeAll(b);     // 差集：[a]
```

**HashSet 的哈希原理：**
```java
// 当调用 add("hello") 时：
// 1. 计算 "hello".hashCode()（得到哈希值）
// 2. 通过哈希值找到对应桶（bucket）
// 3. 如果桶为空 → 直接放入
// 4. 如果桶不为空 → 遍历桶内元素，用 equals() 比较
// 5. 如果 equals 返回 true → 不添加（返回 false）
// 6. 否则 → 放入桶中（链表或红黑树）
```

### 3.2 LinkedHashSet

```java
// 继承 HashSet，底层是 LinkedHashMap
// 维护元素的插入顺序（双向链表）

Set<String> set = new LinkedHashSet<>();
set.add("c");
set.add("a");
set.add("b");
// 遍历顺序：c → a → b（插入顺序）
// 与 HashSet 不同，HashSet 的顺序不保证
```

### 3.3 TreeSet

```java
// 底层：TreeMap（红黑树）
// 特点：有序（自然顺序或 Comparator）、O(log n) 查找
// 元素必须实现 Comparable 或在构造时传入 Comparator

Set<String> set = new TreeSet<>();           // 自然顺序
Set<String> desc = new TreeSet<>(Comparator.reverseOrder());  // 逆序

set.add("c");
set.add("a");
set.add("b");
// 遍历顺序：a → b → c（自然顺序）

// TreeSet 扩展操作
TreeSet<Integer> ts = new TreeSet<>();
ts.addAll(Arrays.asList(1, 3, 5, 7, 9));

ts.first();              // 1（最小）
ts.last();               // 9（最大）
ts.lower(5);             // 3（小于 5 的最大值）
ts.higher(5);            // 7（大于 5 的最小值）
ts.floor(5);             // 5（小于等于 5 的最大值）
ts.ceiling(5);           // 5（大于等于 5 的最小值）
ts.subSet(2, 8);         // [3,5,7]（范围为 [2, 8)）
ts.headSet(5);           // [1,3]（小于 5）
ts.tailSet(5);           // [5,7,9]（大于等于 5）
```

### 3.4 Set 的选择

| | HashSet | LinkedHashSet | TreeSet |
|:---|:---|:---|:---|
| 底层 | HashMap | LinkedHashMap | TreeMap（红黑树） |
| 顺序 | 无序 | 插入顺序 | 排好序 |
| 时间复杂度 | O(1) | O(1) | O(log n) |
| 要求 | equals + hashCode | equals + hashCode | Comparable 或 Comparator |

## 5. Map 接口

### 5.1 HashMap

```java
// 底层：数组 + 链表/红黑树（JDK 8+）
// 特点：O(1) 查找，无序，key 可为 null

Map<String, Integer> map = new HashMap<>();
map.put("a", 1);
map.put("b", 2);
map.put("c", 3);
map.put("a", 10);          // 覆盖旧值，返回旧值 1

map.get("a");              // 10
map.getOrDefault("d", 0);  // 0
map.containsKey("a");      // true
map.containsValue(10);     // true（O(n)）
map.size();                // 3
map.isEmpty();             // false

// 遍历方式
for (Map.Entry<String, Integer> entry : map.entrySet()) {
    entry.getKey();
    entry.getValue();
}

for (String key : map.keySet()) { }

for (Integer value : map.values()) { }

// JDK 8+ 遍历
map.forEach((key, value) -> System.out.println(key + "=" + value));

// JDK 8+ 的增强方法
map.computeIfAbsent("d", k -> 4);       // 不存在则计算
map.computeIfPresent("a", (k, v) -> v + 1);  // 存在则更新
map.merge("a", 10, Integer::sum);       // 合并值
map.putIfAbsent("e", 5);               // 不存在才放
```

**HashMap 的底层原理（JDK 8+）：**
```java
// 核心字段
static final int DEFAULT_INITIAL_CAPACITY = 1 << 4;  // 16（初始容量）
static final float DEFAULT_LOAD_FACTOR = 0.75f;       // 负载因子
static final int TREEIFY_THRESHOLD = 8;               // 链表转红黑树阈值
static final int UNTREEIFY_THRESHOLD = 6;             // 红黑树转链表阈值
static final int MIN_TREEIFY_CAPACITY = 64;           // 最小树化容量

// put 流程：
// 1. 计算 key.hashCode()，再通过 hash() 方法扰动（高 16 位异或低 16 位）
// 2. 通过 (n - 1) & hash 计算桶索引（n 为数组长度）
// 3. 如果桶为空 → 直接放入
// 4. 如果桶不为空 → 遍历链表/红黑树：
//    a. 如果 key 已存在 → 覆盖 value
//    b. 如果 key 不存在 → 追加到链表末尾（尾插法，JDK 7 头插）
// 5. 如果链表长度 ≥ 8 且数组长度 ≥ 64 → 树化为红黑树
// 6. 如果元素数 > 容量 × 负载因子 → 扩容（resize）

// 哈希扰动函数
static final int hash(Object key) {
    int h;
    return (key == null) ? 0 : (h = key.hashCode()) ^ (h >>> 16);
}
// 将哈希码的高 16 位与低 16 位异或，使高 16 位也参与寻址
// 因为 (n-1) & hash 只用到 hash 的低位（n 一般不大）
```

**HashMap 扩容机制：**
```java
// 扩容条件：size > capacity * loadFactor
// 例如：16 * 0.75 = 12，第 13 个元素插入时触发扩容

// 扩容过程：
// 1. 新容量 = 旧容量 << 1（翻倍）
// 2. 创建新数组（2 倍长度）
// 3. rehash：重新计算每个元素在新数组中的位置
//    关键优化：因为容量翻倍（n 变为 2n），
//    每个元素要么在原来的索引位置，要么在原索引 + 旧容量位置
//    判断依据：hash & oldCap == 0（原位置）或 != 0（原位置 + oldCap）
// 4. JDK 7：头插法（并发扩容可能死循环）
//    JDK 8+：尾插法（解决了并发死循环问题，但仍非线程安全）

// 扩容的代价：
// 每次扩容需要 O(n) 的 rehash
// 如果预知数据量，指定初始容量避免多次扩容：
// int expectedSize = 1000;
// int capacity = (int) (expectedSize / 0.75f) + 1;
// Map<String, ?> map = new HashMap<>(capacity);
```

**HashMap JDK 7 vs JDK 8+：**

| | JDK 7 | JDK 8+ |
|:---|:---|:---|
| 数据结构 | 数组 + 链表 | 数组 + 链表 + 红黑树 |
| 插入方式 | 头插法 | 尾插法 |
| 扩容后 rehash | 全部重算 | hash & oldCap 优化 |
| 扰动函数 | 4 次位运算 | 1 次位运算 |
| 并发问题 | 扩容死循环 | 数据丢失 |

### 5.2 LinkedHashMap

```java
// 继承 HashMap，维护双向链表记录顺序
// 两种模式：插入顺序（默认）、访问顺序

// 插入顺序
LinkedHashMap<String, Integer> map = new LinkedHashMap<>();
map.put("c", 3);
map.put("a", 1);
map.put("b", 2);
// 遍历顺序：c → a → b（插入顺序）

// 访问顺序（可用于实现 LRU 缓存）
LinkedHashMap<String, Integer> lru = new LinkedHashMap<>(16, 0.75f, true) {
    @Override
    protected boolean removeEldestEntry(Map.Entry<String, Integer> eldest) {
        return size() > 3;  // 超过 3 个元素时删除最久未访问的
    }
};

lru.put("a", 1);
lru.put("b", 2);
lru.put("c", 3);
lru.get("a");           // 访问 a，a 移到最后
lru.put("d", 4);        // 超过 3 个，删除最老的 b
// 此时 lru 包含：a, c, d
```

### 5.3 TreeMap

```java
// 底层：红黑树（自平衡二叉查找树）
// 特点：有序（自然顺序或 Comparator）、O(log n)

TreeMap<String, Integer> map = new TreeMap<>();
map.put("c", 3);
map.put("a", 1);
map.put("b", 2);
// 遍历顺序：a → b → c（键的自然顺序）

// 扩展操作
map.firstKey();             // "a"
map.lastKey();              // "c"
map.lowerKey("b");          // "a"
map.higherKey("b");         // "c"
map.subMap("a", "c");       // {a=1, b=2}
map.headMap("b");           // {a=1}
map.tailMap("b");           // {b=2, c=3}
```

### 5.4 Map 的选择

| | HashMap | LinkedHashMap | TreeMap | ConcurrentHashMap |
|:---|:---|:---|:---|:---|
| 顺序 | 无序 | 插入/访问顺序 | 键排序 | 无序 |
| 时间复杂度 | O(1) | O(1) | O(log n) | O(1) |
| 线程安全 | ❌ | ❌ | ❌ | ✅ |
| null key | ✅（1个） | ✅ | ❌ | ❌ |
| null value | ✅ | ✅ | ✅ | ❌ |

### 7.2 ConcurrentHashMap

```java
// 与同步的 HashMap 相比，ConcurrentHashMap 性能更好（分段锁/无锁）
// JDK 7：Segment 分段锁
// JDK 8+：CAS + synchronized（锁粒度更细）

Map<String, Integer> concurrentMap = new ConcurrentHashMap<>();

    // 遍历反映集合的当前状态，但不抛 ConcurrentModificationException
}
```

## 9. Fail-Fast 与 Fail-Safe

```java
// Fail-Fast：检测到并发修改时立即抛 ConcurrentModificationException
// 通过 modCount 机制实现

// Fail-Fast 示例：
List<String> list = new ArrayList<>(Arrays.asList("a", "b", "c"));
for (String s : list) {
    if (s.equals("b")) {
        // list.remove(s);  // ❌ ConcurrentModificationException！
    }
}

// 正确删除方式：
// 1. Iterator.remove()
Iterator<String> it = list.iterator();
while (it.hasNext()) {
    if (it.next().equals("b")) {
        it.remove();  // ✅
    }
}

// 2. JDK 8+ 的 removeIf
list.removeIf(s -> s.equals("b"));  // ✅

// Fail-Safe：并发安全集合（迭代器不抛异常，但可能看到过时的数据）
// 例如：ConcurrentHashMap、CopyOnWriteArrayList
```

## 10. 常见面试题

### Q1: HashMap 的容量为什么总是 2 的幂？
```java
// 计算桶索引时使用位运算：(n - 1) & hash
// n 为 2 的幂时，n-1 的二进制全是 1
// (n-1) & hash 等价于 hash % n，但位运算更快

// 示例：n = 16（10000），n-1 = 15（1111）
// hash = 123456 → (1111) & (二进制...) = 0~15 均匀分布

// 如果 n 不是 2 的幂，n-1 有 0 位，某些桶永远用不到
// 例如 n = 15（1111），n-1 = 14（1110），最低位总是 0
// 奇数索引的桶永远不会被使用，哈希冲突概率翻倍
```

### Q2: HashMap 和 Hashtable 的区别？
```java
// 1. 线程安全：Hashtable 的 put/get 都有 synchronized
//              HashMap 非线程安全
// 2. null 键值：HashMap 允许 1 个 null key 和多个 null value
//               Hashtable 不允许 null
// 3. 初始容量：HashMap 16，Hashtable 11
// 4. 扩容方式：HashMap 翻倍，Hashtable 翻倍+1
// 5. 遍历方式：HashMap 迭代器是 fail-fast
//               Hashtable 的 Enumeration 不是 fail-fast
```

### Q3: ArrayList 和 LinkedList 的插入性能对比？
```java
// 尾部插入：
// ArrayList：O(1) 平摊，不扩容时
// LinkedList：O(1)

// 头部插入：
// ArrayList：O(n)（移动所有元素）
// LinkedList：O(1)

// 中间插入：
// ArrayList：O(n)（移动部分元素）
// LinkedList：O(n)（查找位置 O(n) + 插入 O(1)）
// 所以中间插入两者都不好
```

## 11. 最佳实践

1. **使用接口类型声明变量**：`List<String> list = new ArrayList<>()` 而非 `ArrayList<String>`
2. **预估初始容量**：避免集合频繁扩容
3. **`List.of`/`Set.of`/`Map.of` 创建不可变集合**：JDK 9+
4. **遍历时删除用 `Iterator.remove()` 或 `removeIf()`**
5. **`HashMap` 自定义 key 必须重写 `equals` 和 `hashCode`**
6. **使用 `computeIfAbsent` 简化 map 中的初始化逻辑**
7. **`ConcurrentHashMap` 替代 `Collections.synchronizedMap`**
8. **无修改需求时使用不可变集合**
9. **`数组` → `List`：`Arrays.asList()`（注意返回的 List 大小固定）**
10. **`List` → `数组`：`list.toArray(new T[0])`**
